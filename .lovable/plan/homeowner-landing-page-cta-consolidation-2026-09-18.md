# Homeowner landing page CTA consolidation

## Scope
Only simplify the public homeowner landing page. Preserve its approved design, section order, imagery, routes, trust content, and all logged-in experiences.

## Changes
1. **Header and opening section**
   - Make the homepage’s prominent action read **Post a Job** and keep its existing `/post-job-brief` destination.
   - Retain Quote Checker as a visually secondary text link because the opening copy explicitly discusses existing quotes.
   - Remove the extra competing tools link from the opening action cluster; Platform Tour remains available in navigation.

2. **Journey choice panel**
   - Make **Post a Job** the first and strongest choice.
   - Keep **Quote Checker** as the secondary choice for homeowners who already have a quote.
   - De-emphasise Manage My Project and Platform Tour as supporting navigation rather than equal calls-to-action, preserving their current routes.

3. **Process and trust sections**
   - Keep the verification, launch-area, process, and differentiation information.
   - Tighten only repeated journey wording so the main path remains “need work done → Post a Job.”
   - Preserve useful informational links such as Our Checks, How matching works, and About as low-emphasis links.

4. **Final action section**
   - Use one primary **Post a Job** button.
   - Keep Quote Checker as a secondary text link for visitors who already have a quotation.
   - Remove the repeated Platform Tour action from this section; it remains in the site navigation and journey panel.

## Validation
- Check the live page at desktop and mobile widths.
- Confirm the primary Post a Job links reach `/post-job-brief`.
- Confirm the retained Quote Checker links reach `/quote-checker` without matching the primary visual emphasis.
- Confirm no overflow, overlap, broken imagery, or accidental changes to other pages.
